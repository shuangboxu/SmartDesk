spaces

“学 / 工 / 乐”空间入口，保持卡片与导航的一致性

SmartDesk 在保持界面简洁的导航与卡片式布局基础上，在日期左侧新增 “学（Learn）”、“工（Work）”、“乐（Fun）” 的极简标签， 切换时仅替换当前场景的卡片组合，不更改导航结构或引入新层级。

学 · Learn 工 · Work 乐 · Fun

学习空间 · Learn

将主页、笔记、任务与课表、空教室、图书馆座位与聊天等模块按学习场景排列，按需展现。

  • Home 启动页（Free 不可用，Plus/Pro 可打开）
  • 笔记、任务与课表联动提醒，聊天助手随时记录
  • 空教室与图书馆座位数据实时可视
  • 聊天区与 AI 助手保持学习语境

工作空间 · Work

图片、幻灯片与文件工具以卡片形式加入，提高学习计划外的文档效率，卡片仅在对应空间出现。

  • 图片格式转换（正在开发）
  • PPT 备注与文字提取工具（待完成）
  • 文件工具：压缩、查看与轻量共享入口

娱乐空间 · Fun

听歌与视频下载等轻量功能在娱乐空间以卡片或入口方式存在，保持主界面清爽。

  • B 站与 YouTube 视频下载（尚未完成）

设置页支持任意空间任意功能做启动页、隐藏不想要的模块、同空间左右排序，甚至跨空间共享卡片（如听歌同时出现在学习与娱乐模块）。

  • 自定义启动页：任意空间 + 任意功能
  • 隐藏不需要的功能卡片
  • 同一空间内左右排序功能卡片
  • 跨空间复用模块（听歌可呈现在学习与娱乐）
capabilities

覆盖“预约 + 学习”全链路的桌面体验

图书馆助手与学习工具共享统一界面和数据存储，全部功能默认离线可用，联网仅发生在必要的学校接口或你授权的 AI API。

图书馆自动助手

LibrarySeatView 提供持续搜索、定时任务、在线抢座与历史追踪；Free/Plus 需手动确认，Pro 可无人值守。

空教室与自习室

FreeRoom 模块实时展示教学楼占用，为临时讨论或复习提供可视化参考。

笔记 · 任务 · AI

内置 SQLite 存储，支持任务提醒、笔记管理、聊天助理与文档总结，可选接入在线模型。

Home 视图

Plus/Pro 可打开 Home 页面，展示提醒、状态与个性化启动模块。

娱乐与下载

B 站、YouTube 视频下载等轻量功能以极简卡片存在，工具仍在开发中，但不会改变整体导航结构。

automation engine

会员驱动的自动化与配额系统

PremiumQuotaTracker、OnlineSeatUsageTracker 与 LicenseValidator 协同工作：记录配额、验证授权、限制在线抢座提交次数，确保公平与透明。

设备与学号绑定

license.json 绑定 deviceId + 统一身份认证学号。RSA-SHA256 签名防篡改，时间源防回拨。设置页可随时导入、禁用或切换模式。

配额守护

Free/Plus/Pro 每月 5/150/500 次持续搜索与定时配额。Pro 在线抢座：10 次/日 + 授权天数总额度。所有记录保存在 premium-usage.json 与 online-seat-usage.json。

数据透明

用户数据、授权状态、日志全部在本地 ~/.smartdesk。无云端收集，手动分享日志可定位问题。详见 信任中心 与 公平说明。
