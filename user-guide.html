PART 1

SmartDesk 是什么？ What is SmartDesk?

一款专为北理工同学设计的桌面学习工作台。 A desktop cockpit designed specifically for BIT students.

SmartDesk 是一款专为 北理工同学 设计的桌面应用，把这些事情集中在一个界面里完成：

  • 查看今日课表、任务和作业 Deadline
  • 查询空闲教室、自习室
  • 自动或半自动抢图书馆座位（Pro 会员支持在线抢座）
  • 管理笔记和待办事项
  • 使用 AI 助手提问、改代码、写总结
数据存储说明： 软件默认在本地运行，学习数据保存在你自己的电脑里，只在需要访问学校系统或你授权的 AI 服务时联网。

SmartDesk is a desktop app tailored for BIT students. It combines all of these workflows in one place:

  • Review today’s classes, tasks, and assignment deadlines
  • Find empty classrooms and study rooms
  • Reserve or auto-grab library seats (online grabbing is a Pro perk)
  • Manage notes and to-dos
  • Ask the AI assistant questions, debug code, or draft summaries
Data policy: SmartDesk runs locally. Your study data stays on your computer and only goes online when talking to campus systems or AI services you approve.
PART 2

第一次使用：安装与准备 First Use: Install & Prepare

建议按顺序完成安装、填写个人信息、配置偏好以及（可选）AI Key 设置。 Follow these steps to install, fill in your profile, set preferences, and (optionally) add an AI key.

2.1 安装与启动

  1. 运行安装包，按向导完成安装；桌面或开始菜单会出现 “SmartDesk” 图标。
  2. 双击图标，进入名为 “SmartDesk 工作台” 的主界面。
提示：Free 模式默认已启用，无需额外注册即可体验大部分学习功能。

2.1 Install & launch

  1. Run the installer and follow the wizard. A “SmartDesk” shortcut appears on the desktop/start menu.
  2. Double-click it to open the SmartDesk Workbench main window.
Tip: Free mode is turned on by default, so you can try most study features without any signup.

2.2 填写个人信息与偏好（推荐）

  1. 点击右上角橙色的 “打开设置” 按钮，弹出系统设置窗口。
  2. 左侧选择 “个人信息”，填写：
    • 统一身份认证学号
    • 统一身份认证密码（用于访问图书馆、课表等学校系统）
  3. 在与 图书馆座位 / 空闲教室 相关的设置中，按提示完成：
    • 图书馆座位偏好（偏好阅览室、是否靠窗/靠墙、优先级范围等）
    • 空闲教室偏好（校区、教学楼范围、连续空闲节次数等）

完善这些信息后，首页推荐、图书馆快速预约和空闲教室推荐才能发挥最佳效果。

2.2 Complete your profile & preferences (recommended)

  1. Click the orange Open Settings button in the top-right corner.
  2. Under Profile enter:
    • Your unified authentication student ID
    • Your password (used to access the library, schedule, and other campus systems)
  3. In the Library Seats / Free Rooms sections, set up:
    • Seat preferences (reading rooms, window/wall preference, priority tiers, etc.)
    • Free-room preferences (campus, buildings, continuous free slots)

Completing these fields makes homepage suggestions, quick seat booking, and free-room recommendations much more accurate.

2.3 配置 AI Key（可选）

  1. 在设置窗口中选择 “AI 聊天设置”。
  2. 根据自己使用的服务填写 OpenAI API Key 或 DeepSeek API Key：
    • OpenAI：https://platform.openai.com
    • DeepSeek：https://platform.deepseek.com
  3. 不配置 API Key 也能使用本地/基础模式，但无法使用部分在线大模型能力。

2.3 Add an AI API key (optional)

  1. In Settings, open AI Chat Settings.
  2. Enter the OpenAI API Key or DeepSeek API Key you already own:
    • OpenAI: https://platform.openai.com
    • DeepSeek: https://platform.deepseek.com
  3. You can use the local/basic mode without any key, but online model capabilities will be limited.

PART 4

工作台首页：一眼看到今天要做什么 Home dashboard: know what to do today

首页主要面向 Plus / Pro 用户开放，Free 用户可以直接从对应模块进入。 The dashboard is a Plus/Pro feature, but Free users can open each module directly.

说明： 首页功能主要面向 Plus / Pro 用户开放；Free 用户可以直接从课表、空闲教室或图书馆模块进入。

点击顶部导航中的 “首页” 标签，可以看到一个汇总今日学习状态的总览页面，主要包含四个区域。

Heads up: The Home dashboard unlocks with Plus/Pro. Free users can open Schedule, Free Rooms, or Library modules directly.

Open the Home tab to see a single-page summary of today’s status built around four widgets.

4.1 今日课表总览

  • 显示 当前日期、教学周 和今天的全部课程。
  • 中央的 “下一节课” 卡片会突出显示最近的一节课，包括：
    • 课程名称（例如：大学物理 II（全英文））；
    • 周次、第几节课；
    • 上课时间与教室。
  • 卡片下方会给出简单建议，例如上一节在哪、下一节在哪个教室自习更方便。
  • 点击 “查看当前课程详情” 可以查看更完整的课程信息。

4.1 Today’s schedule overview

  • Shows the current date, teaching week, and all classes for today.
  • The “next class” card highlights your upcoming class with:
    • Course title
    • Week/day/slot
    • Time and room
  • A tip below the card suggests where you just were and where to study next.
  • Click View course details for the full record.

4.2 任务提醒

  • 右侧展示最近一条或几条即将到期的任务，例如：“第九周作业 到期”。
  • 列出截止时间（如 11-28 23:30）和简要说明。
  • 点击 “查看当前任务详情” 会跳转到任务模块查看详情或直接勾选完成。

4.2 Task reminders

  • The panel lists one or more tasks that are close to their deadline, e.g., “Week 9 assignment”.
  • Each entry shows the due time and a short description.
  • Click View task to jump into the Tasks module and mark it done.

4.3 图书馆偏好推荐

  • 根据你在图书馆模块中设置的 偏好座位，系统每天会推荐一批适合当前时段的座位。
  • 每张卡片显示：
    • 阅览室名称（如：视听学习空间 09X）；
    • 座位号和可用时间段。
  • 点击卡片下方 “预约” 按钮，即可按偏好顺序快速尝试预约。
  • 底部还有 “刷新推荐”、“打开图书馆快速预约” 等按钮，方便进入更详细的预约界面。

4.3 Library seat suggestions

  • Uses your seat preferences to recommend rooms and seats that match the current time.
  • Each card shows:
    • Reading room name
    • Seat number and available time slots
  • Click Reserve to attempt seats in your priority order.
  • Use Refresh suggestions or Open quick booking for the detailed seat view.

4.4 空闲教室推荐

  • 系统会根据当前时间和课表占用情况，自动筛选附近适合自习或讨论的空教室。
  • 你可以在偏好设置中指定：
    • 校区 / 教学楼或教学楼组；
    • 从现在起希望连续空闲的节次数（如希望连续空闲 2–3 节）。
  • 首页卡片会展示若干推荐教室，点击 “查看详情 / 查看空闲教室” 跳转到空闲教室模块查看完整列表。
小建议： 每天打开电脑后先看一眼首页——今天上什么课、有哪些作业、去哪里学习，一目了然。

4.4 Free classroom picks

  • The system filters nearby classrooms that are free for self-study or group work based on the current time.
  • In Preferences you can define:
    • Campus / building / building groups
    • How many consecutive slots you need (e.g., 2–3 periods)
  • The card lists a few rooms; click View details to jump to the complete free-room list.
Daily habit: Start your day by checking Home—classes, tasks, and study spots become obvious in seconds.
PART 5

课表与任务：按周掌控所有安排 Schedule & tasks: control everything by week

通过一个日历视图集中查看课程、Deadline 与个人事件，并把任务列表与之同步。 Use a calendar view to see classes, deadlines, and personal events, then sync tasks onto the same timeline.

5.1 课表视图与日期

  • 左上角可以切换 日 / 周 / 月 视图；
  • 中间显示当前日期和第几教学周；
  • 点击 “今天” 按钮，会自动跳回当日位置。

5.1 Calendar view & timeline

  • Switch between Day / Week / Month views in the top-left corner.
  • The center shows the current date and teaching week.
  • Click Today to jump back instantly.

5.2 与学校系统同步

  • “拉取乐学任务”：从乐学/在线教学平台同步作业与课程任务，自动标记为 Deadline 或待办；
  • “拉取课表”：从教务系统获取最新课表，避免自己手动录入和遗漏变更。

同步后，课程和任务会以不同颜色块显示在时间轴上，鼠标悬停或点击即可查看详情。

5.2 Sync with campus systems

  • Fetch LeXue tasks to pull assignments from the online learning platform.
  • Fetch schedule to refresh the official timetable.

Synced courses and tasks appear as colored blocks on the timeline; hover or click for details.

5.3 事件类型筛选

你可以通过勾选/取消勾选来控制显示内容，例如：

  • 课表安排；
  • 作业 Deadline；
  • 个人事件或纪念日；
  • 课表变更提醒。

在复习周或考试周，只保留 “Deadline + 考试” 类型，可以更专注于关键事项。

5.3 Filter event types

Toggle which layers appear—examples:

  • Classes
  • Assignment deadlines
  • Personal events / reminders
  • Schedule change notices

During exam weeks, keep only “deadlines + exams” to stay focused.

5.4 任务管理

  • 顶部切换到 “任务” 标签，可以新建任务、设置截止时间并添加备注；
  • 随时标记任务完成，保持首页提醒与课表视图同步；
  • 勾选 “将任务同步到课表视图”，就能在日历中与课程一起查看。

配合 “拉取乐学任务” 使用，可将线上作业自动导入任务列表，减少遗漏。

5.4 Task management

  • Under the Tasks tab, create tasks, due dates, and notes.
  • Check items off any time so the dashboard stays in sync.
  • Enable Sync tasks to calendar to show them next to classes.

Combined with Fetch LeXue tasks, online assignments land in your list automatically.

PART 6

聊天：用 AI 助手答疑与写作 Chat: ask AI for help & writing

配置 API Key（详见 2.3）后，就能在 SmartDesk 中直接与模型交流、整理代码与生成学习计划。 Add an API key (section 2.3) to chat with models, debug code, and draft study plans inside SmartDesk.

6.1 聊天（AI 助手）

使用前： 需要购买并配置可用的 API Key，详见上文 2.3。

点击 “聊天” 标签，会看到：

  • 左侧：对话历史列表，可按话题分组、折叠不同会话；
  • 中间：支持代码块和长文本排版的对话窗口；
  • 下方：输入框与 “发送” 按钮，支持 Ctrl + Enter 快速发送。

常见用法：

  • 让 AI 解释课程难点、作业题或实验步骤；
  • 粘贴报错日志，请它给出修改建议或优化方案；
  • 根据课表和 Deadline 生成复习节奏或时间管理建议。

界面底部还提供了一些实用功能：

  • “隐藏隐私内容”：折叠敏感信息，便于录屏或分享；
  • “插入素材 / 插入块料”：把笔记、任务等选中文本快速加入对话；
  • “上传文件”：直接把代码或作业文件交给 AI 分析。

不同模型对文件/图片的支持不同。暂不支持的格式，SmartDesk 会仅发送必要的文字描述，避免泄露多余信息。

6.1 Chat (AI assistant)

Before using: add a valid API key—see section 2.3.

Inside the Chat tab you’ll find:

  • Left: a conversation list organized by topic
  • Center: a rich conversation pane with code blocks and long-form formatting
  • Bottom: input box + Send button (Ctrl + Enter shortcut)

Typical use cases:

  • Ask AI to explain tricky course content or assignment prompts
  • Paste error logs for debugging tips
  • Generate study rhythms or plans based on your schedule

Handy tools at the bottom:

  • Hide sensitive content for clean recordings or sharing
  • Insert snippet to pull selected notes/tasks straight into the chat
  • Upload file to send homework or code directly

Model support for files/images varies. When a format isn’t supported, SmartDesk only sends necessary text so your data stays safe.

PART 7

图书馆座位助手：预约、持续搜索与抢座 Library seat assistant: reserve, monitor, auto-grab

把“刷 i 北理 抢座位”这一件事，交给 SmartDesk 帮你盯着。 Let SmartDesk watch iBiti and handle reservations for you.

7.1 刷新状态与当前预约

  1. 点击顶部醒目的 “刷新状态” 按钮：
    • 检查你是否已通过统一身份认证登录；
    • 读取当前已有的预约和在用座位。
  2. 中间 “预约状态” 表格会显示：
    • 阅览室、座位号、预约开始/结束时间；
    • 当前状态（使用中 / 已完成 / 等待生效等）。
  3. 表格下方常见操作按钮：
    • “签离”：使用结束后主动签离座位；
    • “取消预约”：不再需要时释放座位；
    • “临时离开”：短暂离开座位但希望保留。

7.1 Refresh status & current reservations

  1. Hit Refresh status to:
    • Confirm you’re logged in via unified authentication
    • Load ongoing and upcoming reservations
  2. The Reservation status table shows room, seat, start/end time, and current state.
  3. Actions underneath include Sign out, Cancel, and Temporary leave.

7.2 快速预约

右侧的 “快速预约” 区块适合你已经配置好偏好时使用：

  • 选择预约日期（通常是当天或次日）；
  • 根据需要微调优先级和日期范围；
  • 点击 “立即预约合适座位”，系统会按偏好顺序依次尝试预约。

如果预约失败，失败原因会显示在上方状态区域，例如配额不足、座位已被占用、网络异常等。

7.2 Quick reservation

Use the Quick reservation block after you’ve set seat preferences:

  • Pick a booking date (today or tomorrow)
  • Adjust priority tiers/date range if needed
  • Click Reserve suitable seats to try seats in priority order

Failures (quota, occupied seats, network errors) appear in the status area.

7.3 持续搜索：帮你盯着空位

适用场景： 热门时段、你仍在电脑前但不想频繁刷新页面。
  1. 在 “持续搜索” 区域设置：
    • 预约日期（如今天）；
    • 可接受的 优先级下限/上限（例如 Tier 0–2）；
    • 刷新间隔（例如每 5 秒或 10 秒）。
  2. 点击 “开始持续搜索”：
    • SmartDesk 会定期查询符合条件的座位；
    • 一旦出现空位，即自动提交预约请求。
  3. 随时可以点击 “停止” 结束搜索。

不同会员等级的典型使用方式（仅示意，具体以软件内说明为准）：

  • Free：每月约 5 次，需要在电脑前手动确认关键操作；
  • Plus：每月约 150 次，同样需要手动确认，适合高频使用但愿意自己盯状态；
  • Pro：每月约 500 次，更适合复习季长期开启，但仍建议合理使用以避免滥用。

7.3 Continuous search

Best for: peak hours when you’re at the computer but don’t want to refresh constantly.
  1. Configure Continuous search with date, priority range, and refresh interval.
  2. Click Start so SmartDesk polls seats and auto-submits when one appears.
  3. Stop anytime.

Typical quotas:

  • Free: ~5/month with manual confirmation
  • Plus: ~150/month, still manual confirmation
  • Pro: ~500/month, ideal for exam seasons (use responsibly)

7.4 定时抢座：在关键时间点自动出手

适用场景： 图书馆清晨放座位（如早上 6 点）等固定放号时间。
  1. 在 “定时抢座” 区域选择：
    • 预约日期（想去的那天）；
    • 抢座开始时间（例如 06:00）；
    • 优先级下限/上限；
    • 抢座持续时长（例如 5 分钟）。
  2. 点击 “开启定时抢座”：
    • 系统会在设定时间自动开始尝试预约；
    • 在设定的时长内不断重试，直到成功或达到时间上限。

使用时需要注意：

  • Free / Plus：电脑必须保持开机且 SmartDesk 正在运行，并在关键步骤进行 手动确认；
  • Pro：同样需要电脑在线和程序运行，但不再需要手动确认，更适合睡觉或上课不方便看电脑时使用。

7.4 Scheduled grabs

Best for: fixed release times (e.g., 6:00 a.m.).
  1. Choose booking date, start time, priority range, and duration.
  2. Click Start scheduled grab. SmartDesk submits attempts during that window.

Requirements:

  • Free/Plus: keep the computer on with SmartDesk running; confirm key actions manually.
  • Pro: still requires the computer online, but manual confirmation is waived—great for early mornings.

7.5 在线抢座（Pro 专属）

在图书馆页面的子标签中切换到 “在线抢座”，可以看到一个专为 Pro 设计的自动化页面：

  • 顶部橙色提示条会说明该功能为 Pro 专属，并显示本月剩余在线抢座次数；
  • 可设置：
    • 预约日期（实际使用座位的日期）；
    • 执行日期和执行时间（开始为你抢座的时间点）；
    • 优先级下限/上限；
    • 是否启用 持续搜索（部分高峰时段会限制持续搜索，尤其是早上 6–7 点）；
    • 持续时长（启用持续搜索时生效）。
  • 点击 “提交在线抢座” 后：
    • 任务会出现在 “待执行在线任务” 表格中；
    • 执行结果会记录在 “最近在线抢座记录” 区域，包括时间、座位信息和成功/失败原因。

典型场景：

  • 清晨放号时间想多睡一会儿，不方便守在电脑前；
  • 上课过程中无法频繁打开电脑或手机刷新偏好座位，但又不想错过好位置。

使用提醒：

  • 在线持续搜索期间，如果你在手机上通过 “i 北理” 登录图书馆页面，或在电脑浏览器中手动刷新官网，有可能打断服务器端任务；
  • 一旦通过在线任务成功抢到座位，桌面端会弹出提示并自动刷新状态；
  • Pro 用户的图书馆偏好中，默认会在持续搜索时跳过自动刷新，建议保持默认设置以减少干扰。

7.5 Online grabs (Pro only)

Switch to the Online grabs tab for a fully automated page designed for Pro members.

  • An orange banner reminds you of remaining online attempts this month.
  • Configure booking date, execution date/time, priority range, whether to enable continuous search (some hours block it), and duration.
  • After submitting, tasks appear in Upcoming online jobs, with results logged in Recent online grabs.

Typical scenarios:

  • Early-morning releases when you’d rather keep sleeping
  • Classes where you can’t keep checking seats

Reminders:

  • Manual visits to iBiti during an online search can interrupt the server job.
  • Once a seat is grabbed, the desktop app notifies you and refreshes status automatically.
  • The default Pro preference skips auto-refresh during continuous search—keep it that way to avoid conflicts.
