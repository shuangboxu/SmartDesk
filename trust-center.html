Trust · Privacy · Transparency

SmartDesk 信任中心

聚焦“用户关系”三大主题：数据落地、联网行为与授权安全。答案均来源于当前 SmartDesk 源码（LicenseValidator、MembershipService、OnlineSeatUsageTracker 等）。

数据落地策略

所有业务数据、授权状态、配额与日志均保存在 ~/.smartdesk：SQLite DB、membership-state.json、premium-usage.json、online-seat-usage.json 等，均可自行备份或删除。

联网与本地平衡

默认离线运行，仅在以下情形联网：1) 获取图书馆/空教室数据；2) 在线抢座提交（Pro）；3) 授权时间校验；4) 你主动启用的 AI API。其它逻辑在本地线程完成。

授权文件原理

license.json 含 deviceId、学号、过期时间与 tier，附带 RSA-SHA256 签名。LicenseValidator 校验设备、学号、签名、剩余天数，任何字段不符即视为无效。

隐私承诺

SmartDesk 不内置登录或云端账号，不收集真实姓名/学号以外的敏感信息。deviceId 在本地生成，仅用于授权校验。日志不会自动上传。

撤销与自助

删除 license.json 即回到 Free；可在设置页点击“禁用会员”临时关闭高级功能；需要重置数据时，删除整个 ~/.smartdesk 目录即可。

防止走捷径

授权绑定设备 + 学号，配额即便手动修改 JSON 也会按硬上限（5/150/500/10）重新计算。若发现异常使用，将吊销证书并拒绝更新。

常见问题

Q：如何验证 license.json 真伪？ A：可使用 SmartDesk 附带的 LicenseGeneratorUI 或任何 RSA 验签工具，配合 README 中的公钥验证签名。
Q：迁移设备需要做什么？ A：在新电脑安装 SmartDesk，复制新的 deviceId，与旧授权信息一起联系作者重新生成 license，新旧设备互不干扰。
Q：AI 模块会上传我的数据吗？ A：只有在你主动填写 API Key 并点击发送时才会调用在线模型，未开启时聊天助手保持离线，全部数据存本地。
Q：误删数据如何恢复？ A：提前备份 ~/.smartdesk 目录即可快速恢复。建议定期打包该目录到网盘或移动硬盘。
